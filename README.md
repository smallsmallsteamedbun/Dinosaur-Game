## 小恐龙跑酷游戏

![Dino-Game](https://oss.mcso.top/wordpress/2025/09/20250927153948204.png)

> 课程设计一个星期做的游戏，但还算有头有尾，起码是个完整的游戏。

## 源代码部署

**程序源代码**在code文件夹里面，直接打开就能编译运行的。我用的是VS 2022，所以项目文件的格式是VS的样子，当然基于easyx应该没有人用的不是VS吧。

## 可执行程序

**打包出来的可执行程序**在pack文件夹里，就是编译好的exe程序带着素材文件夹Data，需要将exe程序和Data文件放在同一个目录下，程序才能识别运行。

## 游戏展示

**两个MP4文件**是游戏的视觉展示，游戏流程.mp4是整体游戏流程全过程展示，火山.mp4是单个场景的视觉展示。

**设计文档.pdf**就是设计元素的描述，像是一个说明文档。
